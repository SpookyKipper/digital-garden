# Reactions of Haloalkanes
## Hydrolysis (Substitution)

### Replace X (e.g. Br) with OH
### $\ce{R-X + NaOH ->[reflux][heat] R-OH + NaBr}$
e.g.  $\ce{CH3-CH2-CH2-CH2-Br + OH ->[reflux][heat] CH3-CH2-CH2-CH2-OH + Br-}$

```smiles
Br-C-C-C-C
O-C-C-C-C
```


# Reactions of Alcohols
## Substitution with halides (Cl/Br/I)
### Replace OH with X
### $\ce{R-OH + HX ->[reflux] R-X + H2O}$
### $\ce{3 R-OH + PX3 ->[reflux] 3 R-X + H3PO3}$

e.g. $\ce{CH3CH2-OH + HCl ->[reflux] CH3ClH2-Cl + H2O}$

## Dehydration (Elimination of Water)
Removes $\ce{H + OH}$
### $\ce{CH3CH2OH ->[strong acid][heat] -> CH2=CH2 + H2O}$
```smiles
O-C-C
C=C
```


## Oxidation
##### Primary (1$^{\circ}$ alcohols) 
$\ce{C(R)(OH)(H)(H) ->[O] C=O(R)(H) ->[O] C=O(R)(OH)}$
```smiles
O-CC
C=O CC

```
##### Primary (2$^{\circ}$ alcohols)
$\ce{C(R)(OH)(R)(H) ->[O] C=O(R)(H)}$ -> Resist Oxidation
##### Primary (3$^{\circ}$ alcohols)
$\ce{C(R)(OH)(R)(H)}$ -> Resist Oxidation
